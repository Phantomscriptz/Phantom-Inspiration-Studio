# Phantom Inspiration Studio — Roadmap

## Completed baseline

- [x] Separate YouTube long-form and Shorts workflows.
- [x] Focused niche picker with selected-only, scrollable sub-topic tabs.
- [x] Script quality gate: hook, length, duplicate, source, and medical-claim checks.
- [x] WhisperX word-timing bridge and subtitle fallback.
- [x] Audio normalization and review package generation.
- [x] Optional licensed B-roll selection and attribution records.
- [x] Generate-only publishing safety default.
- [x] YouTube audience sync/cache and initial Analytics screen.
- [x] Storage usage and scoped generated-media cleanup.
- [x] File Explorer launcher.

## Current priority — reliable first production

1. Run one generate-only motivational test with no B-roll.
2. Verify the script length, narration, captions, visual sequence, audio mix, thumbnail, and review package.
3. Make the primary AI visual provider reliable; treat a provider outage as a clear fallback, never a crash.
4. Run a private/unlisted YouTube upload test only after the output is approved.

## Next product milestones

- [ ] Full official YouTube Analytics reports: views, retention, subscriber movement, and topic feedback.
- [ ] Meta (Facebook/Instagram) official authentication and analytics.
- [ ] TikTok official authentication and analytics.
- [ ] Per-platform preflight: dimensions, duration, metadata, disclosure, source, and upload status.
- [ ] Optional 4K long-form export profile with source-quality checks.
- [ ] Resumable render/upload diagnostics and clear recovery instructions.
- [ ] Packaging: stable one-folder installer, then signed release process.

## Before any public sale

- [ ] Security and secret review.
- [ ] License/attribution review for all visual/audio assets.
- [ ] Repeatable end-to-end tests on a clean Windows machine.
- [ ] Accurate platform-support matrix; do not market incomplete upload integrations as complete.
- [ ] Terms, privacy policy, support workflow, and update mechanism.
